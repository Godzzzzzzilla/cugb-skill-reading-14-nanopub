# Limits

| condition | behaviour |
|---|---|
| verb outside the closed set | no triple, `confidence: unspecified` |
| passive with unstated agent | grammatical subject kept |
| noun that is also a verb | only chosen when no earlier verb exists |
| multiple claims in one sentence | the first relation wins; the rest is in the object |
| non-English text | verb set is English; claims fall through to `unspecified` |
